## 🔧 ФУНКЦІОНАЛЬНІ МОДУЛІ

### 1. Система керування проєктами ✅

**Можливості:**
- Створення, перегляд, редагування, видалення проєктів (CRUD)
- Метадані проєкту:
  - Назва (обов'язково, до 200 символів)
  - Підзаголовок (до 300 символів)
  - Локація (до 200 символів)
  - Рік (до 20 символів)
  - Площа (до 50 символів)
  - Теги (до 15 штук)
- Завантаження hero-зображень у Supabase Storage
- Валідація даних на клієнті та сервері
- Пагінація списку (10 проєктів на сторінку)
- Фільтрація за локацією, роком, тегами
- Сортування за назвою, роком, датою створення
- Пошук за назвою

### 2. Система керування статтями (Posts) ✅

**Можливості:**
- Два статуси: "Чернетка" (draft) / "Опубліковано" (published)
- Автогенерація URL-slug з української транслітерацією
- Hero-блок статті з зображенням, заголовком, тегами, локацією, роком
- Галерея зображень до статті
- Фільтрація за статусом та пошук

**Page Builder** — конструктор контенту з 4 типами блоків:

| Тип блоку | Опис | Поля |
|-----------|------|------|
| `text_full` | Повнотекстовий блок | content, label, area, months, year |
| `image_full` | Повноекранне зображення | image_url, alt, caption |
| `text_image` | Текст ліворуч + зображення праворуч | text, image_url, image_alt, icon, label, title, features |
| `image_text` | Зображення ліворуч + текст праворуч | text, image_url, image_alt, icon, label, title, features |

**Функції Page Builder:**
- Drag-and-drop сортування блоків
- Додавання/видалення блоків
- Редагування вмісту кожного блоку
- Завантаження зображень для блоків
- Попередній перегляд hero-блоку

### 3. SEO-модуль ✅

**Налаштування SEO для статей:**
- SEO Title (до 60 символів)
- SEO Description (до 160 символів)
- OG-зображення для соціальних мереж (Facebook, Twitter, etc.)
- Індикатор стану SEO у списку статей ("Налаштовано" / "Не налаштовано")

### 4. Система автентифікації ✅

**Можливості:**
- Вхід за email та паролем
- JWT-токени для авторизації запитів
- Захищені маршрути (ProtectedRoute)
- Автоматичний редирект на login при 401
- Вихід з системи (logout)
- Збереження токена в localStorage

### 5. Журнал активності (Activity Log) ✅

**Логування дій:**
- `create` — створення сутності
- `update` — оновлення сутності
- `delete` — видалення сутності

**Що логується:**
- Email користувача
- Тип сутності (project, post)
- ID та назва сутності
- Деталі змін (які поля оновлено, кількість блоків, медіа)

**Функції журналу:**
- Фільтрація за користувачем
- Фільтрація за типом дії
- Пагінація записів

### 6. Медіа-менеджмент ✅

**Можливості:**
- Завантаження зображень у Supabase Storage
- Автоматичне видалення старих зображень при заміні
- Видалення зображень при видаленні сутності
- Підтримка множинних зображень (галерея)
- Ліміт розміру запиту: 50MB

## 📡 API ENDPOINTS

### Публічні ендпоінти

```
GET  /api/portfolio              # Список проєктів з пагінацією та фільтрацією
GET  /api/portfolio/all          # Проєкти + статті разом (для сторінки портфоліо)
GET  /api/portfolio/filters      # Доступні фільтри (теги, локації, роки)
GET  /api/portfolio/:id          # Деталі проєкту за ID
GET  /api/posts/public/:slug     # Публічна стаття за slug
GET  /health                     # Health check сервера
```

### Захищені ендпоінти (потрібна автентифікація)

**Автентифікація:**
```
POST   /api/admin/login          # Вхід (email, password)
POST   /api/admin/logout         # Вихід
```

**Проєкти:**
```
POST   /api/portfolio            # Створити проєкт
PUT    /api/portfolio/:id        # Оновити проєкт
DELETE /api/portfolio/:id        # Видалити проєкт
```

**Статті:**
```
GET    /api/posts                # Список статей (з фільтрацією)
GET    /api/posts/:id            # Деталі статті
POST   /api/posts                # Створити статтю
PUT    /api/posts/:id            # Оновити статтю
DELETE /api/posts/:id            # Видалити статтю
POST   /api/posts/:id/gallery    # Додати зображення до галереї
DELETE /api/posts/:id/gallery    # Видалити зображення з галереї
```

**Журнал активності:**
```
GET    /api/logs                 # Список записів журналу
GET    /api/logs/users           # Список унікальних користувачів
```

## 🗄️ СТРУКТУРА БАЗИ ДАННИХ (Supabase/PostgreSQL)

### Таблиці

| Таблиця | Призначення | Основні поля |
|---------|-------------|--------------|
| `users` | Користувачі адмін-панелі | id, email, password_hash, created_at |
| `projects` | Проєкти портфоліо | id, title, subtitle, image_url, tags, location, year, area, created_at, updated_at |
| `project_media` | Медіа-файли проєктів | id, project_id, url, role, sort_order |
| `posts` | Статті/сторінки | id, title, slug, status, seo_title, seo_description, og_image_url, hero_*, gallery_images, created_at, updated_at |
| `blocks` | Блоки контенту статей | id, post_id, type, data (JSONB), sort_order, created_at |
| `activity_logs` | Журнал дій | id, user_email, action, entity_type, entity_id, entity_title, changes (JSONB), created_at |

### Зв'язки

- `project_media.project_id` → `projects.id` (one-to-many)
- `blocks.post_id` → `posts.id` (one-to-many)
